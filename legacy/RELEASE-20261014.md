# Company auto-update release — 14 October 2026

Includes remembered per-user posting months, monthly Overview/ledger/reports, administrator-only amount editing, centered delete confirmation with retained audit history, group/particular code editing and numeric ordering, compact Excel reports, subtotal-only posting, removal of Vehicle UI, and local administrator backup-restore wizard.

Overview, Cash ledger and Reports now check for saved changes every five seconds while visible. Changes refresh the current view with its applied filters. Unsaved filter selections and open delete confirmations defer refresh; entry/edit forms do not auto-refresh. Network interruptions retry automatically. Existing open browser tabs need one manual refresh after upgrading.

## Download / installation

Download the attached **KYS-Finance-Company-Auto-Update-20261014.zip** asset, not GitHub's automatic source ZIP. Extract the entire folder and follow COMPANY-INSTALL.md. The archive contains the EXE, required bundled Python runtime and helper scripts; it is not a signed Setup.exe/MSI. Windows 7 prerequisites documented in COMPANY-INSTALL.md are still separate.

Existing installations: back up first, stop the server, preserve data/backups/restore-recovery/configuration, and update in the same installation folder as described in COMPANY-INSTALL.md. Never overwrite company data with a test database. Company bootstrap requires an administrator chosen during installation; no demo users/database are included.

## Backup

Read **BACKUP-GUIDE.md** (Sinhala) inside the package. Local snapshots run at server start and every two hours while running, retaining 60 copies. External destination must be configured on a separate USB drive or NAS. Automatic external backup is the first successful snapshot per day; use Overview → Back up database at day-end for a fresh external copy. Restore replaces data/users and is not a merge. Startup occurs after the configured Windows user signs in, not before sign-in.
